# Электронный каталог книг

Веб-приложение для управления каталогом книг и авторов.

## Стек технологий

- **Платформа:** .NET 9 (ASP.NET Core)
- **База данных:** MariaDB (MySQL)
- **Доступ к базе данных:** Dapper (микро-ORM). Не создаёт жёсткой привязки к конкретной СУБД — привязка определяется только синтаксисом SQL-запросов.
- **Веб-интерфейс:** Razor Pages

## Функциональность

### Книги
- Просмотр списка книг
- Добавление книги
- Редактирование книги
- Удаление книги

### Авторы
- Просмотр списка авторов
- Добавление автора
- Редактирование автора
- Удаление автора

## Модель данных

Идентификаторы записей — целые числа с автоматическим приращением (до ~2,1 млрд записей). UUID избыточен.

### Книга
| Поле | Тип | Описание |
|------|-----|----------|
| Id | int | Первичный ключ |
| Title | string | Название книги |
| PageCount | int | Количество страниц |
| Description | string | Описание книги (Markdown) |
| Authors | `List<Author>` | Авторы книги (связь многие-ко-многим) |

### Автор
| Поле | Тип | Описание |
|------|-----|----------|
| Id | int | Первичный ключ |
| FullName | string | ФИО автора |
| Description | string | Краткое описание (биография) |
| Books | `List<Book>` | Книги автора |

### Связь книга-автор (промежуточная таблица)
| Поле | Тип | Описание |
|------|-----|----------|
| BookId | int | Внешний ключ → Книга.Id |
| AuthorId | int | Внешний ключ → Автор.Id |

Первичный ключ — составной (BookId, AuthorId).

## Постраничный вывод

Списки книг и авторов разбиваются на страницы. Максимальное количество записей на одной странице списка задаётся константой в коде и на данном этапе не делается настраиваемым.

## Валидация

Ограничения задаются константами в коде и не делаются настраиваемыми.

- Название книги: не более 500 символов
- Описание книги: не более 65535 символов, поддерживается разметка Markdown (ограничение обусловлено типом TEXT в MySQL/MariaDB)
- Количество страниц в книге: положительное число
- ФИО автора: не более 500 символов
- Описание автора: не более 65535 символов, поддерживается разметка Markdown (ограничение обусловлено типом TEXT в MySQL/MariaDB)

## Выбор Razor Pages

Для данного проекта выбраны Razor Pages как наиболее простой вариант серверного рендеринга в ASP.NET Core. Альтернативы — MVC (избыточная структурированность для каталога), Minimal API (потребуется отдельный фронтенд), Blazor (тяжеловесен для данной задачи). Razor Pages позволяют писать HTML-шаблоны с вкраплениями C#, обеспечивают встроенную обработку форм, валидацию и повторное использование разметки (общие шаблоны страниц).

## Среда разработки

### Установка .NET 9 SDK (ROSA Linux 13)

```
sudo dnf install dotnet-sdk-9.0
```

### Установка и настройка MariaDB

```
sudo dnf install mariadb
sudo systemctl enable --now mariadb
sudo mysql_secure_installation
```

Перед запуском скрипта инициализации замените пароль в `sql/init-db.sql`.

```
sudo -u mysql mysql < sql/init-db.sql
```

Проверка:

```
sudo -u mysql mysql -e "USE booklibrary; SHOW TABLES; DESCRIBE Books; DESCRIBE Authors; DESCRIBE BookAuthors;"
```

### Настройка подключения к базе данных

В `BookLibrary/appsettings.json` в строке подключения `DefaultConnection` указать параметры: адрес сервера, имя пользователя, пароль.

Установить зависимости:

```
cd BookLibrary
dotnet add package MySqlConnector
dotnet add package Dapper
```

### Запуск приложения

```
cd BookLibrary
dotnet watch
```

Приложение запускается на `http://localhost:5198`. При изменении файлов автоматически перекомпилируется и перезапускается. Для доступа извне используется обратный прокси.

### Установка и настройка обратного прокси (Angie)

```
sudo dnf install angie
sudo cp angie.conf /etc/angie/angie.conf
sudo systemctl restart angie
```

## Развертывание

Приложение работает за обратным прокси. Подойдёт любой обратный прокси, используется Angie.
