# Электронный каталог книг

Веб-приложение для управления каталогом книг, периодических изданий и авторов.

## Стек технологий

- **Платформа:** .NET 9 (ASP.NET Core)
- **База данных:** Microsoft SQL Server
- **Доступ к базе данных:** Dapper (микро-ORM). Не создаёт жёсткой привязки к конкретной СУБД — привязка определяется только синтаксисом SQL-запросов.
- **Веб-интерфейс:** Razor Pages

## Функциональность

### Книги
- Просмотр списка книг
- Добавление книги
- Редактирование книги
- Удаление книги

### Авторы
- Просмотр списка авторов
- Добавление автора
- Редактирование автора
- Удаление автора

### Периодические издания
- Просмотр списка периодических изданий
- Добавление периодического издания
- Редактирование периодического издания и списка его авторов
- Удаление периодического издания

## Модель данных

Идентификаторы записей — целые числа с автоматическим приращением (до ~2,1 млрд записей). UUID избыточен.

### Книга
| Поле | Тип | Описание |
|------|-----|----------|
| Id | int | Первичный ключ |
| Title | string | Название книги |
| PageCount | int | Количество страниц |
| Description | string | Описание книги (Markdown) |
| Authors | `List<Author>` | Авторы книги (связь многие-ко-многим) |

### Автор
| Поле | Тип | Описание |
|------|-----|----------|
| Id | int | Первичный ключ |
| FullName | string | ФИО автора |
| Description | string | Краткое описание (биография) |
| Books | `List<Book>` | Книги автора |

### Периодическое издание
| Поле | Тип | Описание |
|------|-----|----------|
| Id | int | Первичный ключ |
| Title | string | Название издания |
| Description | string | Описание издания (Markdown) |
| Authors | `List<Author>` | Авторы издания (связь многие-ко-многим) |

### Связь книга-автор (промежуточная таблица)
| Поле | Тип | Описание |
|------|-----|----------|
| BookId | int | Внешний ключ → Книга.Id |
| AuthorId | int | Внешний ключ → Автор.Id |

Первичный ключ — составной (BookId, AuthorId).

### Связь периодическое издание-автор (промежуточная таблица)
| Поле | Тип | Описание |
|------|-----|----------|
| PeriodicalId | int | Внешний ключ → Периодическое издание.Id |
| AuthorId | int | Внешний ключ → Автор.Id |

Первичный ключ — составной (PeriodicalId, AuthorId).

## Постраничный вывод

Списки книг, периодических изданий и авторов разбиваются на страницы. Максимальное количество записей на одной странице списка задаётся константой в коде и на данном этапе не делается настраиваемым.

## Валидация

Ограничения задаются константами в коде и не делаются настраиваемыми.

- Название книги: не более 500 символов
- Описание книги: не более 100000 символов, поддерживается разметка Markdown
- Количество страниц в книге: положительное число
- Название периодического издания: не более 500 символов
- Описание периодического издания: не более 100000 символов, поддерживается разметка Markdown
- ФИО автора: не более 500 символов
- Описание автора: не более 100000 символов, поддерживается разметка Markdown

Тип `NVARCHAR(MAX)` в MS SQL Server вмещает до ~1 млрд символов. Указанные ограничения задаются валидацией в приложении и при необходимости могут быть изменены.

## Выбор Razor Pages

Для данного проекта выбраны Razor Pages как наиболее простой вариант серверного рендеринга в ASP.NET Core. Альтернативы — MVC (избыточная структурированность для каталога), Minimal API (потребуется отдельный фронтенд), Blazor (тяжеловесен для данной задачи). Razor Pages позволяют писать HTML-шаблоны с вкраплениями C#, обеспечивают встроенную обработку форм, валидацию и повторное использование разметки (общие шаблоны страниц).

## Среда разработки

### Установка .NET 9 SDK (ROSA Linux 13)

```
sudo dnf install dotnet-sdk-9.0
```

### Установка и настройка Microsoft SQL Server

```
sudo curl -o /etc/yum.repos.d/mssql-server.repo https://packages.microsoft.com/config/rhel/9/mssql-server-2025.repo
sudo dnf install mssql-server
sudo /opt/mssql/bin/mssql-conf setup
sudo systemctl enable --now mssql-server
sudo curl -o /etc/yum.repos.d/mssql-tools.repo https://packages.microsoft.com/config/rhel/9/prod.repo
sudo dnf install mssql-tools
```

Перед запуском скрипта инициализации замените пароль в `mssql/init-db.sql`.

```
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P '<пароль_админа>' -i mssql/init-db.sql
```

Проверка:

```
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P '<пароль_админа>' -Q "USE booklibrary; SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES;"
```

Добавление тестовых данных:

```
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -i mssql/test-data.sql
```

### Настройка подключения к базе данных

В `BookLibrary/appsettings.json` в строке подключения `DefaultConnection` указать параметры: адрес сервера, имя пользователя, пароль.

Установить зависимости:

```
cd BookLibrary
dotnet add package Microsoft.Data.SqlClient
dotnet add package Dapper
dotnet add package Markdig
```

### Запуск приложения

```
cd BookLibrary
dotnet watch
```

Приложение запускается на `http://localhost:5198`. При изменении файлов автоматически перекомпилируется и перезапускается. Для доступа извне используется обратный прокси.

### Установка и настройка обратного прокси (Angie)

```
sudo dnf install angie
sudo cp angie.conf /etc/angie/angie.conf
sudo systemctl restart angie
```

## Развертывание

Приложение работает за обратным прокси. Подойдёт любой обратный прокси, используется Angie.
